# तेजस घुसळे — Einstein Files

A Marathi-language, fictional friendship-parody photo archive. Includes 14 separate photo files, a responsive gallery, search, filters, and a fullscreen file viewer.

## Publish on GitHub Pages
1. Create a **new GitHub repository** (for example `tejas-files`).
2. Upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, `main`, `/ (root)`, then **Save**.
5. Wait for GitHub Pages to provide your site URL.

You can also open `index.html` locally to preview. No build tools are needed.

**Important:** GitHub Pages is public. Get permission before publishing another person's photos. This site is an obvious fictional joke and not a genuine criminal or government record.
